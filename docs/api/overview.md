# API — Обзор

Backend API построен на **FastAPI** и доступен по префиксу `/api`.

## Базовый URL

```
http://10.1.30.165/api
```

## Интерактивная документация

FastAPI автоматически генерирует интерактивную документацию:

- **Swagger UI**: [/api/docs](http://10.1.30.165/api/docs)
- **ReDoc**: [/api/redoc](http://10.1.30.165/api/redoc)

## Эндпоинты

| Метод | Путь | Описание | Авторизация |
|-------|------|----------|-------------|
| `GET` | `/api/health` | Проверка состояния сервера | Нет |
| `POST` | `/api/auth/register` | Регистрация пользователя | Нет |
| `POST` | `/api/auth/login` | Вход, получение JWT | Нет |
| `GET` | `/api/auth/me` | Данные текущего пользователя | JWT |

## Формат ответов

Все ответы возвращаются в формате JSON.

### Успешный ответ

```json
{
  "status": "ok"
}
```

### Ошибка

```json
{
  "detail": "Описание ошибки"
}
```

## Аутентификация

API использует JWT Bearer Token. Подробнее в разделе [Аутентификация](./authentication).
