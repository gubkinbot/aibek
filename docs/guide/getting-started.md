# Начало работы

AI-платформа АО «Узтрансгаз» — это веб-приложение для работы с искусственным интеллектом, анализом данных и автоматизацией бизнес-процессов.

## Требования

- Docker и Docker Compose
- Git

## Быстрый старт

```bash
# Клонировать репозиторий
git clone https://github.com/gubkinbot/aibek.git
cd aibek

# Запустить все сервисы
docker compose up --build -d
```

После запуска платформа доступна по адресу: **http://10.1.30.165**

| Сервис | URL |
|--------|-----|
| Веб-приложение | http://10.1.30.165 |
| Документация | http://10.1.30.165/docs/ |
| API Swagger | http://10.1.30.165/api/docs |
| API Health | http://10.1.30.165/api/health |
