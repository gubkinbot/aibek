# Начало работы

AI-платформа АО «Узтрансгаз» — корпоративная веб-платформа для работы с искусственным интеллектом, анализом данных и автоматизацией бизнес-процессов.

## Что умеет платформа

- **Регистрация и авторизация** — только корпоративная почта `@utg.uz`, подтверждение по email, JWT-токены
- **Система ролей (RBAC)** — superadmin, admin, пользовательские роли с гибкими правами
- **Панель администрирования** — управление пользователями, ролями, группами, подразделениями
- **Аудит-лог** — все действия администраторов записываются с IP-адресом
- **Мультиязычность** — русский и узбекский языки
- **Тёмная тема** — переключение dark/light mode

## Требования

- Docker и Docker Compose (v2+)
- Git

## Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone https://github.com/gubkinbot/aibek.git
cd aibek

# 2. Настроить переменные окружения
cp .env.example .env
# Отредактируйте .env — как минимум JWT_SECRET и POSTGRES_PASSWORD

# 3. Запустить всё
docker compose up --build -d
```

Через 30–60 секунд все сервисы будут готовы.

## Доступные адреса

После запуска платформа доступна по адресу сервера (по умолчанию — порт 80):

| Сервис | URL | Описание |
|--------|-----|----------|
| Веб-приложение | `http://<сервер>/` | Основной интерфейс платформы |
| API документация | `http://<сервер>/api/docs` | Swagger UI — интерактивная документация API |
| Документация проекта | `http://<сервер>/docs/` | Эта документация (VitePress) |
| Health check | `http://<сервер>/api/health` | Проверка работоспособности API |

## Первые шаги после запуска

### 1. Зарегистрируйтесь

Откройте веб-приложение и нажмите «Регистрация». Используйте корпоративную почту `@utg.uz`.

### 2. Подтвердите email

На вашу почту придёт 6-значный код. Введите его на странице подтверждения.

### 3. Настройте суперадмина

Если ваш email совпадает с `SUPERADMIN_EMAIL` из `.env`, вы автоматически получите роль суперадминистратора после подтверждения email.

### 4. Войдите в систему

После подтверждения email войдите с вашим паролем. Суперадмину будет доступна панель администрирования в боковом меню.
