# Конфигурация

Все параметры системы настраиваются через переменные окружения в файле `.env`.

## Переменные окружения

### База данных (TimescaleDB)

| Переменная | Описание | По умолчанию |
|------------|----------|-------------|
| `POSTGRES_USER` | Имя пользователя БД | `aibek` |
| `POSTGRES_PASSWORD` | Пароль БД | — |
| `POSTGRES_DB` | Имя базы данных | `aibek_db` |
| `DATABASE_URL` | Полный URL подключения | Автогенерация |

### Аутентификация (JWT)

| Переменная | Описание | По умолчанию |
|------------|----------|-------------|
| `JWT_SECRET` | Секретный ключ для подписи токенов | — |
| `JWT_ALGORITHM` | Алгоритм подписи | `HS256` |
| `JWT_EXPIRATION_MINUTES` | Время жизни токена (минуты) | `1440` (24ч) |

### Redis

| Переменная | Описание | По умолчанию |
|------------|----------|-------------|
| `REDIS_URL` | URL подключения к Redis | `redis://redis:6379/0` |
